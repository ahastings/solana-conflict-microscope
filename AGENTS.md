# Project rules

- This repository is an analytical and educational Solana developer tool, never a trading system.
- Use only public, read-only Solana data. Never create/import wallets, handle private keys, submit transactions, purchase tokens, or access financial accounts.
- Do not implement automated trading, arbitrage, MEV extraction, transaction sniping, bundle submission, or private-auction reconstruction.
- Describe results as declared account contention, potential parallelism, and estimated execution waves. Never claim to reconstruct a validator's exact private schedule.
- Do not claim novelty without competitive evidence. Prefer primary technical sources and record uncertainty or contradictory evidence.
- Keep dependencies modest, TypeScript strict, fixtures reproducible, and tests deterministic.
- Never push or publish without explicit permission.
