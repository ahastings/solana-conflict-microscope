# Changelog

## 1.1.0 — 2026-10-14

- Link directly to a selected transaction, saved slot, or exact upload chunk. Links restore the inspector after reload and work in saved HTML reports.
- Find the GitHub source, feedback chooser, and MIT license from the demo opening page.
- File comparison now checks work and potential-conflict budgets before reconstructing conflicts, keeping small but expensive inputs from exhausting browser memory. Detailed browser limits are expandable.
- GitHub deployments run the browser interaction checks as well as portable data verification. The browser driver is a pinned development dependency; generated reports remain self-contained.
- Fresh Windows clones retain the intended source line endings. Public fixture and research-plan bytes stay unchanged.
- Structured bug and explanation forms help contributors provide reproducible feedback.

These changes preserve the underlying example analyses, wave bounds and recorded evidence. They do not extend runtime, semantic-counterfactual, or validator-scheduling claims.

## 1.0.0

First public portable microscope release under MIT, with captured devnet examples, synthetic teaching data, interactive reports, independent declared-evidence verification and saved-analysis comparison. The public browser file-comparison page was added as a follow-up before 1.1.0.
